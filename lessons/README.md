# Уроки (lessons)

По одному заданию на занятие. Формат каждого урока одинаковый, чтобы его можно
было открыть в новой сессии и сразу понять, что делать.

## Структура урока

1. **Цель** — что должно заработать к концу занятия.
2. **Теория** — что нужно понять перед практикой (кратко, со ссылками на документацию).
3. **Задание** — что реализовать самостоятельно.
4. **Критерии готовности** — как проверить, что шаг сделан.
5. **Подсказки** — только если застрял (читай по одной).
6. **Проверка** — что покажет наставнику результат.
