# dashulya-study

Учебный проект: пошагово собираем собственного Telegram-агента с памятью,
изучая фреймворк [AG2](https://docs.ag2.ai/). Ориентир по архитектуре и
поведению — бот [Dashulya](https://github.com/Lancetnik/dashulya) (MIT),
но это самостоятельная реализация, а не форк.

## Как устроен проект

- [`SPEC.md`](SPEC.md) — цель, объём, роли, сценарии и критерии приёмки.
- [`ROADMAP.md`](ROADMAP.md) — учебный маршрут с отметками прогресса.
- [`AGENTS.md`](AGENTS.md) — правила наставничества для новой сессии.
- [`PROGRESS.md`](PROGRESS.md) — текущее состояние и точка продолжения.
- [`lessons/`](lessons/) — по одному заданию на занятие.

## Запуск

Инструкции появляются по мере прохождения шагов. Первое занятие — `lessons/00-empty-project.md`.
